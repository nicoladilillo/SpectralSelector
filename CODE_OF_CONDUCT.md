# Code of Conduct

SpectralSelector is intended to be a respectful, inclusive scientific-software
community. Participants must communicate constructively, respect different
backgrounds and levels of experience, and critique methods and evidence rather
than people.

Harassment, discriminatory language, personal attacks, deliberate intimidation,
and publication or use of another person's private information are not
acceptable in project spaces.

Project maintainers may edit or remove contributions and temporarily or
permanently restrict participation when behavior is inconsistent with these
expectations. Reports should be sent privately to the maintainer through the
security contact described in `SECURITY.md`. Reports will be reviewed promptly,
kept confidential as far as practical, and handled without retaliation.

This policy applies to the repository, documentation, issue tracker, review
discussions, and public events where a person represents the project.
