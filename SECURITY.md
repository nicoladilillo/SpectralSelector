# Security Policy

## Supported versions

Until the first stable release, security fixes are made on the latest released
minor version only.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's private security
advisory feature in the SpectralSelector repository. Include the affected version,
a minimal reproduction, likely impact, and any suggested mitigation.

The maintainer will acknowledge a report within seven days and will coordinate
disclosure after a fix is available. Scientific errors without a security
impact should use the normal issue tracker.
