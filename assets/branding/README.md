# SpectralSelector branding

The editable source assets are:

- `spectralselector-logo.svg`: horizontal logo and wordmark for documentation,
  repository pages, and publications.
- `spectralselector-mark.svg`: compact mark for favicons and avatars.

PNG versions are generated from the SVG sources for tools that do not support
vector images. The palette uses navy `#12314A`, teal `#39A6A3`, coral `#E05263`,
and white.

Before a public release, complete a trademark and visual-similarity check for
the project name and identity.
